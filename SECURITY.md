# Security policy

## Report a vulnerability

Don't report security vulnerabilities through public GitHub issues.

Report vulnerabilities to Grafana Labs by email at [security@grafana.com](mailto:security@grafana.com), or through the [Grafana Labs Bug Bounty Program](https://grafana.com/security/bug-bounty/) if the affected component is in scope.

Include:

- A description of the issue and its impact.
- Steps to reproduce, including any proof-of-concept code.
- The commit or release version you tested against.

Don't disclose the vulnerability publicly until it's been fixed and announced, unless the Grafana Labs security team has told you it's safe to do so.

## Response

The security team will acknowledge your report and keep you informed of the progress towards a fix and disclosure.
Grafana Labs announces security fixes on the [Grafana Labs blog](https://grafana.com/blog/).

## Scope

This policy covers the code in this repository.
For the wider Grafana Labs security policy, refer to [https://grafana.com/security](https://grafana.com/security/).
